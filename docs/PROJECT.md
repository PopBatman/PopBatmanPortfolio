# Projet Portfolio

## Objectifs
1. Publier un portfolio de développeur polyvalent destiné aux recruteurs, démontrant FullStack, architecture et IA agentique.
2. Prouver un workflow reproductible ChatGPT → GitHub Issues → Codex Cloud → PR → CI → fusion humaine, sans infrastructure personnelle ni clé API OpenAI.

## V1
Un dashboard unique personnalisable (Personal Workspace), sidebar bibliothèque de widgets et actions, modales de profil/contact/détails, thèmes clair et sombre, français/anglais. Widgets uniformes, déplacement et resize libres avec superposition sur desktop ; disposition verticale adaptée sur mobile. Contenus : parcours, expertises, formations, réalisations (Botty, LeStudio et workflow agentique), CV et contact. Site statique, responsive, accessible ; contenu vérifiable et publiable. Distinguer les expérimentations des produits opérationnels. Voir [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md) et [CONTENT.md](CONTENT.md) pour les douze ateliers éditoriaux approuvés, les règles de publication et le découpage des contenus.

## Hors périmètre
Backend personnel, base de données, comptes, vente en ligne, backend de formulaire personnel (Formspree approuvé comme service externe), orchestrateur externe, automatisation intégrale non prouvée. Laboratoire IA et domaine personnalisé facultatifs.

## Pilotage
GitHub Issues porte les contrats ; Projects fournit la vue de suivi. Aucun backlog concurrent. Le propriétaire valide architecture, design, contenus, fusion et publication. Mesurer les gestes manuels réels du pilote, pas des gains supposés.
