# Projet Portfolio

## Objectifs
1. Publier un portfolio professionnel FullStack, architecture et IA agentique.
2. Prouver un workflow reproductible ChatGPT → GitHub Issues → Codex Cloud → PR → CI → fusion humaine, sans infrastructure personnelle ni clé API OpenAI.

## V1
Accueil, expertises, réalisations (Botty, LeStudio et workflow agentique), parcours et contact. Site statique, responsive, accessible ; contenu vérifiable et publiable. Distinguer les expérimentations des produits opérationnels.

## Hors périmètre
Backend, base de données, comptes, vente en ligne, formulaire serveur, orchestrateur externe, automatisation intégrale non prouvée. Laboratoire IA et domaine personnalisé facultatifs.

## Pilotage
GitHub Issues porte les contrats ; Projects fournit la vue de suivi. Aucun backlog concurrent. Le propriétaire valide architecture, design, contenus, fusion et publication. Mesurer les gestes manuels réels du pilote, pas des gains supposés.
